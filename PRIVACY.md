# HEALTH Bot — Privacy Policy

_Last updated: September 25, 2026_

This policy tells you what data HEALTH Bot ("the bot") collects, why it collects the data, and how it keeps the data. The bot is operated by binpas ("the operator").

## 1. Data the bot collects

The bot keeps only the data that it needs for its features:

- **Discord IDs:** user IDs, server IDs, channel IDs, role IDs, and message IDs.
- **Usernames:** the Discord username of a user who is part of a moderation action or a ticket.
- **Moderation records:** warnings, jail records (with the roles that the bot removed and will give back), temporary bans, and the reasons that moderators enter.
- **Ticket records:** ticket numbers, open and close times, and notes that staff write about a ticket.
- **Server settings:** the settings that administrators set with `/setup`, reaction-role menus, auto-reactions, trigger words, and permission templates.

## 2. Message content

The bot reads the text of a message only when the server owner turns on message content features, or when the message mentions the bot. The bot uses the text only to reply to or act on that message. The bot does not keep message text in its database.

## 3. Why the bot uses this data

The bot uses the data only to make its features work: moderation, tickets, roles, and server settings. The bot does not use the data for advertising, tracking, or profiling.

## 4. Sharing of data

The operator does not sell, rent, or share your data with other parties. The bot sends data only to Discord, as necessary for the bot to operate.

## 5. Storage and security

The data is kept in one database on a server that the operator controls. Only the operator has direct access to the database. Server moderators can see the records for their server through bot commands.

## 6. How long the bot keeps data

The bot keeps data until a server administrator or the operator deletes it. If the bot leaves a server, the operator can delete the data for that server.

## 7. Your choices

You can ask the operator to show you or delete the data that the bot keeps about you. To do this, send a message on Discord to **binpas**. Note: the operator can keep moderation records if a server needs them for safety reasons.

## 8. Children

You must be old enough to use Discord under the [Discord Terms of Service](https://discord.com/terms) to use the bot.

## 9. Changes to this policy

The operator can change this policy at any time. The date at the top of this page shows the last change.

## 10. Contact

For questions about this policy, send a message on Discord to **binpas**.
